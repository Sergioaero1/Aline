## 🇧🇷 Versão em Português

### ✨ Descrição

**Aline Diversidades** é uma plataforma educacional desenvolvida com HTML, CSS e JavaScript puro, voltada para o ensino da Língua Brasileira de Sinais (Libras). O projeto apresenta uma interface moderna, responsiva e cheia de personalidade, com foco em valorizar a inclusão, a acessibilidade e o aprendizado da comunicação visual.

---

### 🎯 Objetivos

- Criar uma vitrine digital para conteúdos e videoaulas de Libras  
- Facilitar o contato direto via WhatsApp com suporte personalizado  
- Integrar com plataformas externas para ampliar o alcance educacional  
- Transmitir os valores do projeto: inclusão, empatia, diversidade e acessibilidade  

---

### 🧩 Tecnologias Utilizadas

- **HTML5**  
- **CSS3**  
- **JavaScript Vanilla**

Funcionalidades:
- Alternância de tema claro/escuro  
- Menu mobile com sidebar  
- Scroll suave  
- Botão “voltar ao topo”  
- Preloader animado  
- Efeito de digitação no título  
- Contador animado (opcional)  
- Rastreio via Google Analytics  
- Meta tags dinâmicas para SEO  

---

### 📱 Responsividade

Layout adaptável para todos os dispositivos, com navegação fluida e visual limpo.

---

### 💖 Mensagem da Marca

> “Comunique-se com o coração e as mãos.”  
> Aline Diversidades acredita que aprender Libras é abrir portas para a empatia e a inclusão. Cada aula é pensada com carinho, cada sinal é uma ponte para o entendimento.

## 🇺🇸 English Version

### ✨ Description

**Aline Diversidades** is an educational platform built with pure HTML, CSS, and JavaScript, focused on teaching Brazilian Sign Language (Libras). The project features a modern, responsive interface designed to promote inclusion, accessibility, and visual communication through engaging video lessons and interactive content.

---

### 🎯 Goals

- Create a digital showcase for Libras content and video lessons  
- Enable direct contact via WhatsApp for personalized support  
- Integrate with external platforms to expand educational reach  
- Promote core values: inclusion, empathy, diversity, and accessibility  

---

### 🧩 Technologies Used

- **HTML5**  
- **CSS3**  
- **Vanilla JavaScript**

Features:
- Light/dark theme toggle  
- Mobile sidebar menu  
- Smooth scroll navigation  
- Back-to-top button  
- Animated preloader  
- Typing effect in titles  
- Optional animated counters  
- Google Analytics tracking  
- Dynamic SEO meta tags  

---

### 📱 Responsiveness

Fully responsive layout for all devices, with clean visuals and intuitive navigation.

---

### 💖 Brand Message

> “Communicate with your heart and hands.”  
> Aline Diversidades believes that learning Libras opens doors to empathy and inclusion. Every lesson is crafted with care, and every sign is a bridge to understanding.
