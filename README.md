## 🇧🇷 Versão em Português

### ✨ Descrição

**Aline Diversidades** é uma loja virtual desenvolvida com HTML, CSS e JavaScript puro, voltada para moda acessível e inclusiva. O projeto apresenta uma interface moderna, responsiva e cheia de personalidade, com foco em valorizar a diversidade de estilos e corpos.

---

### 🎯 Objetivos

- Criar uma vitrine digital para produtos de moda feminina e masculina  
- Facilitar o contato direto via WhatsApp com atendimento personalizado  
- Integrar com plataformas externas como Shopee  
- Transmitir os valores da marca: diversidade, estilo, carinho e acessibilidade  

---

### 🧩 Tecnologias Utilizadas

- **HTML5**  
- **CSS3**  
- **JavaScript Vanilla**

Funcionalidades:
- Alternância de tema claro/escuro  
- Menu mobile com sidebar  
- Scroll suave  
- Botão “voltar ao topo”  
- Preloader animado  
- Efeito de digitação no título  
- Contador animado (opcional)  
- Rastreio via Google Analytics  
- Meta tags dinâmicas para SEO  

---

### 📱 Responsividade

Layout adaptável para todos os dispositivos, com navegação fluida e visual limpo.

---

### 💖 Mensagem da Marca

> “Vista-se de quem você é.”  
> Aline Diversidades celebra a beleza única de cada pessoa. Cada peça é escolhida com carinho, cada detalhe pensado para acolher e empoderar.

US English Version
✨ Description
Aline Diversidades is a virtual store built with pure HTML, CSS, and JavaScript, focused on accessible and inclusive fashion. It features a modern, responsive interface designed to celebrate style diversity and body positivity.

🎯 Goals
- Create a digital showcase for fashion products
- Enable direct contact via WhatsApp
- Integrate with platforms like Shopee
- Promote brand values: diversity, style, care, and accessibility

🧩 Technologies Used
- HTML5
- CSS3
- Vanilla JavaScript
Features:
- Light/dark theme toggle
- Mobile sidebar menu
- Smooth scroll
- Back-to-top button
- Animated preloader
- Typing effect in title
- Optional counter animation
- Google Analytics tracking
- Dynamic SEO meta tags

📱 Responsiveness
Fully responsive layout for all devices, with clean visuals and intuitive navigation.

💖 Brand Message
“Dress as who you are.”
Aline Diversidades is more than a store — it’s a space that celebrates your unique beauty.
